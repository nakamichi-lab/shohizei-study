消費税Study v0.1 (2026-10-12)

使い方:
1. index.html をPCのブラウザで開くと動作します。
2. iPhoneではHTTPS対応の静的サイトホスティング等に index.html を配置し、Safariで開くことを推奨します。
3. Safariの共有メニューから「ホーム画面に追加」でショートカットを作れます。
4. データはブラウザのlocalStorageに保存されます。同じURLでも端末・ブラウザをまたいだ同期はありません。
5. 記録・設定からJSONバックアップを定期的に保存してください。

注意点:
- 2026年10月時点の基礎問題を収録した試作品です。税理士試験の内容網羅・学習効果を保証しません。
- 計算問題は簡単な税率算式の練習であり、申告税額計算の各種端数処理や特例を反映しません。
- manifest と Service Worker は実装済みです。HTTPSで公開した後、初回表示とキャッシュ完了後は基本画面のオフライン利用が可能です（国税庁の参照リンクはネット接続が必要）。iOSのホーム画面アイコンの見え方は環境依存です。
- 計測学習時間はページ表示中の概算です。
- 解答済みの問題は繰り返し出題されます。
- CSV/Excel直接読込、AI添削、複数端末同期は未実装です。
